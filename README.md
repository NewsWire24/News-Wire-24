# News Wire 24

News Wire 24 is a real-time automated news portal covering National, International, Sports, Entertainment, Education & Health.

**Owner / Author:** Gaurav Sharma (News Wire 24)

**Features:**
- Real-time updates at 8AM, 12PM, 3PM, 9PM, 12AM IST
- Hindi & English translation support
- 100% original, analytical news with data - No copy-paste
- Copyright-free images (Pexels / File Photos)
- AdSense Ready

**Tech Stack:** GitHub Pages + GitHub Actions + NewsData API + Pexels API

**Website:** https://NewsWire24.github.io/News-Wire-24/
